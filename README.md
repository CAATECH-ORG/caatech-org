# caatech-org

This is the open-source .org website for CAATECH. It is a static website hosted on Google Cloud Storage.

## 🚀 Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## 🌐 Hosting

Deployed to **Google Cloud Storage** as a static website.

## 🛠️ Local Setup

```bash
git clone https://github.com/your-org/org-landing-page.git
cd org-landing-page
open public/index.html # Or use Live Server extension
```

## 🚀 Deployment (GCS)

Make sure you have `gsutil` set up:

```bash
./deploy/deploy.sh
```
